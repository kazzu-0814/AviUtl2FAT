FFmpeg
------
The Windows binaries staged by the release script are the locally verified
``8.1.1-essentials_build-www.gyan.dev`` build from Gyan.dev.  Their embedded
configuration includes ``--enable-gpl --enable-version3 --enable-static``.
Gyan.dev publishes its Windows builds as GPLv3 builds:
https://www.gyan.dev/ffmpeg/builds/

Accordingly, a binary installer that contains ffmpeg.exe or ffprobe.exe is
distributed under GPLv3 terms.  Before publishing that installer, the release
pipeline must include the GPLv3 license text and a durable link or offer for the
corresponding FFmpeg source and build configuration.  The precise command-line
configuration and SHA-256 values used for the staged binaries are recorded in
release/FFMPEG_PROVENANCE.md.  The FFmpeg licensing explanation is available at:
https://ffmpeg.org/legal.html

Whisper/Gemma model weights are not bundled. Model downloads are user initiated.
Codex and Claude CLIs are optional external tools and are not bundled.
