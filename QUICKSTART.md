# AviUtl2 AltFactor — Quick Start

1. Run `AviUtl2-AltFactor-Setup-x.x.x-x64.exe` and select the existing AviUtl2 Plugin folder.
2. In AviUtl2 choose **編集 → プラグイン → AviUtl2 AltFactor → AltFactor を開く**.
3. Choose a video/audio file and click **字幕を作成**.
4. When a Whisper model is required, use **AIモデル管理** and explicitly download it.
5. Edit text directly. Drag-select text in an edit cell, then choose **選択字幕を分解**. Use `Ctrl + click` and **選択字幕を統合** to merge rows.
6. Use **AviUtl2へ出力** to create editable `.object` data.

While recognition is running, **字幕を作成** changes to **停止**. Stopping keeps existing captions.
